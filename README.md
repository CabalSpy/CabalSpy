# CabalSpy

**Multi-chain, real-time KOL & Smart Money intelligence for Solana, BNB and Base.**

CabalSpy tracks a curated set of Key Opinion Leaders, Smart Money wallets and Whales across three chains — monitoring every transaction in real time and surfacing actionable data through an API, WebSocket stream, embeddable widget and web dashboard.

The core idea is simple: the most profitable traders on-chain leave a trail. CabalSpy captures that trail the moment it happens and makes it accessible to traders, developers and platforms that want an edge.

---

## What we offer

**API** — REST endpoints for leaderboards, wallet stats, transaction feeds and per-token analytics across SOL, BNB and Base. Used by trading platforms to surface KOL activity directly inside their product.

**WebSocket** — Real-time transaction stream. Every buy and sell from tracked wallets is pushed the moment it hits the chain, with no polling required.

**Widget** — An embeddable widget that platforms drop into their interface to show live KOL trades for any token being viewed.

**Dashboard** — A web-based leaderboard and analytics tool at [cabalspy.xyz](https://cabalspy.xyz) showing PNL rankings, win rates, trade history and wallet visualizations.

**AlphaBot** — An AI call bot with a 72% hit rate that surfaces high-signal token calls based on KOL activity patterns.

**Chrome Extension** — Scan any token on your trading platform and instantly see which KOLs are invested, how much, and their overall win rate.
